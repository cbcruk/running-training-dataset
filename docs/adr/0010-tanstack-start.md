# ADR 0010 — 브라우즈 계층을 TanStack Start로 옮긴다

**상태:** accepted · 2026-08-16
**대체하는 것:** [ADR 0009](0009-remix-3.md)(Remix 3)
**뒤집는 것:** [ADR 0004](0004-tanstack-router.md)의 "Router, not Start" 판단

---

## 맥락

ADR 0009와 같은 이유로 시작한다. **저장소 소유자가 TanStack Start로 옮기기를 요청했다.**
그러니 이 문서가 답할 것도 같다: 무엇을 지켜야 이 이동이 손실이 아닌가.

다만 이번에는 답해야 할 것이 하나 더 있다. ADR 0004는 Start를 **실측을 근거로 명시적으로
거절했다.**

|          | 엔트리가 보이기까지 (Fast 3G, 4× CPU) | 링크 언퍼러가 보는 것          |
| -------- | ------------------------------------- | ------------------------------ |
| 프리렌더 | **~400 ms**                           | 엔트리별 제목·설명·OG, 1,849자 |
| SPA 셸   | **2,942 ms**                          | 제목 하나, OG 없음, **0자**    |

그 표는 여전히 옳다. 뒤집힌 것은 표가 아니라 **선택지**다. ADR 0004가 읽은 Start 문서는
SPA 모드를 헤드라인으로 걸고 있었고, "빌드를 소유하는 프레임워크를 그 주력 모드를 거절하려고
도입한다"는 것이 거절의 논거였다. 지금 Start는 정적 프리렌더를 1급 기능으로 가진다
(`prerender.enabled`, 경로별 `pages`). base path와 프리렌더가 함께 깨지던 결함
([TanStack/router#5261](https://github.com/TanStack/router/issues/5261),
[#6023](https://github.com/TanStack/router/issues/6023))도 2026-01에 닫혔다.

그래서 이 이동은 **SPA 셸을 받아들이는 것이 아니라, Start를 프리렌더 모드로 쓰는 것**이다.
사전의 48개 라우트는 전부 디스크의 진짜 문서로 남는다. SPA 셸은 이 저장소에 딱 하나 존재하고,
그것이 무엇인지는 아래 "404는 페이지가 아니라 셸이다" 절에 있다.

지켜야 할 것은 ADR 0001이 세운 사전 형태이고, ADR 0009가 물려받은 것과 같다.

- 엔트리마다 디스크에 문서가 하나씩 있고, 각자의 `<title>`·description·canonical·OG를 든다.
- 한 번 로드되면 전체 리로드 없이 넘어가는 조회 도구가 된다.
- 시각물은 데이터의 함수다.
- GitHub Pages에 정적 파일로 나간다. 서버 재작성 규칙 없음.

`remix/ui`는 React가 아니었으므로, 이 이동도 라우터 교체가 아니라 앱 계층 재작성이다.

## 결정

**TanStack Start를 채택한다. 정적 내보내기를 유지한다.**

### 프리렌더 목록은 크롤링이 아니라 데이터에서 온다

`prerender.crawlLinks`와 `autoStaticPathsDiscovery`를 둘 다 끄고, `pages`를
`allPaths()`(`app/data/index.ts`)로 채운다. 크롤링에 맡기면 어느 목록에서도 링크되지 않은
엔트리가 조용히 빠질 수 있고, 그 조용함이 정확히 ADR 0001이 막으려는 실패다. CI는 같은
함수가 아니라 **데이터를 직접 세어** 개수를 대조한다 — 생성기와 검사기가 같은 실수를 하지
않도록.

### base는 한 줄에서 나온다

`vite.config.ts`의 `base` 하나다. Vite가 에셋 URL에 붙이고, Start가 그 값에서 라우터의
`basepath`를 유도해 모든 `<Link>`에 붙인다. ADR 0009에서 링크마다 `url()`을 통과시키던
`app/ui/href.ts`는 사라졌고, 남은 것은 canonical과 `og:url`처럼 **원점까지 필요한 절대
URL**을 만드는 함수 하나뿐이다. 라우터가 결코 만들지 않는 것이 그것이기 때문이다.

### 404는 페이지가 아니라 셸이다

GitHub Pages는 파일이 없는 경로에 `404.html`을 준다. ADR 0009까지는 그 자리에 홈 문서를
복사해 뒀다. Start에서는 그럴 수 없다 — 브라우저가 `/system/오타`에서 홈의 마크업을 받아
라우터가 그리려는 not-found와 맞춰야 하고, React가 하이드레이션 불일치로 죽는다(#418).
실제로 그렇게 죽는 것을 보고 나서 고쳤다.

그래서 `404.html`은 **라우트 내용이 없는 셸**이다(`spa.prerender`). 맞출 것이 없으므로 어떤
URL에서 하이드레이트해도 조용하고, 3.3KB로 홈 문서(15KB)보다 작다. 셸을 굽자면 프리렌더러가
어딘가를 200으로 받아와야 하는데, 그 "어딘가"가 `app/routes/404.tsx`다 — 이 라우트가 존재하는
이유의 전부다.

### 문서 페이로드가 두 겹이 되지 않게 한다

Start의 로더가 돌려주는 값은 하이드레이션 페이로드로 문서에 직렬화된다. 그래서 엔트리
라우트의 로더는 행을 돌려주지 **않는다** — 행이 있는지 확인하고, 최근 본 항목 띠가 쓰는
라벨 하나만 돌려준다. 컴포넌트는 코퍼스에서 직접 읽는다. 코퍼스는 어차피 브라우저 번들에
있고(목록 페이지와 앵커 툴팁이 그것을 필요로 한다), 그러므로 직렬화가 아니라 조회가 싸다.

## 결과

**얻은 것**

- **링크가 타입 검사를 받는다.** `routes.system.href({ id })`가 만들던 문자열이
  `<Link to="/system/$id" params={{ id }}>`가 됐다. 없는 라우트나 빠진 파라미터가 런타임이
  아니라 `vp check`에서 걸린다.
- **base를 붙이는 자리가 사라졌다.** ADR 0009가 "이 비대칭을 지우면 개발 서버에서는 멀쩡히
  통과하면서 배포된 사이트에서만 임포트가 전부 깨진다"고 적어둔 함정이 없어졌다.
- **베타에서 벗어났다.** `remix@3.0.0-beta.6` 고정과, 그 베타가 요구하던 두 우회
  (`@jsxImportSource` 프라그마, 클라이언트 엔트리의 단일 루트 규칙)가 함께 나갔다.
- **테스트가 의존성을 하나 덜 쓴다.** `remix/assert`가 `node:assert` 위의 열 줄짜리 shim이
  됐다.

**치른 것, 그리고 남은 함정**

- **`out/*.svg`의 마크업이 바뀌었다.** 좌표·속성·값은 **한 글자도 다르지 않다** — 바뀐 것은
  직렬화뿐이다(들여쓰기 없음, `<line/>` 대신 `<line></line>`). `renderToStaticMarkup`이
  `remix/ui`의 렌더러와 다르게 직렬화하기 때문이고, 도형은 같은 `app/ui/chart.tsx`에서
  나온다.
- **프리렌더된 문서에 NUL 바이트가 있다.** Start의 하이드레이션 페이로드가 라우트 id
  구분자로 `\x00`을 쓴다. 브라우저는 멀쩡하지만 `grep`은 그 파일을 바이너리로 보고 찾은
  일치를 말하지 않는다 — CI의 검사들이 `grep -a`인 이유이고, 이 저장소에서 프리렌더된
  문서를 손으로 뒤질 때도 같은 플래그가 필요하다.
- **`app/routeTree.gen.ts`는 포맷 검사에서 빠진다.** 생성기가 소유하는 파일이고 Vite가 도는
  모든 명령이 다시 쓴다. 포맷을 고쳐두면 다음 명령이 되돌려놓고 검사가 영원히 빨갛다. 린트와
  타입 검사는 그대로 받고, 커밋된 내용이 `app/routes/`와 맞는지는 CI가 따로 본다.
- **날것의 `<a href>` 함정이 돌아왔다.** ADR 0004가 기록한 그것이다 — 라우터는 평범한 앵커를
  가로채지 않으므로, 날것의 `<a>`는 모든 기능 검사를 통과하면서 내비게이션마다 조용히 전체
  리로드를 한다. 내부 링크는 `<Link>`나 `app/ui/primitives.tsx`의
  `SystemLink`/`WorkoutLink`/`AnchorLink`를 통과해야 한다.
- **최근 본 항목이 한 번 비워진다.** 저장 형태가 완성된 경로에서 종류+id 쌍으로 바뀌었고
  (타입 검사된 링크를 만들기 위해), 키가 `recent:v2`로 올라갔다.
- **Vite+는 남지만 빌드는 하지 않는다.** ADR 0009와 같다. 달라진 것은 `pnpm-workspace.yaml`의
  `overrides`가 나간 것이다 — 모든 `vite` 요구를 Vite+의 rolldown 포크로 갈아끼우고 있었고,
  Start가 peer로 요구하는 `vite >= 7`이 실제로 설치된 그것이어야 한다.

## 검증

ADR 0009가 통과시킨 목록을 그대로 통과시켰다.

- 프리렌더: 48개 문서 + SPA 셸(`404.html`) + `search-index.json`.
- 데이터 스크립트 전부 새 러너(`vite-node`)에서 돌고, 재생성물(`app/data/types/`,
  `docs/verification.md`, `docs/counts.md`)에 드리프트 없음.
- 데이터 규칙 테스트 18개 통과. `vp check` 무경고.
- 실제 브라우저(Chromium, CDP)로 배포 base(`/running-training-dataset/`) 아래에 서빙한
  `dist/client/`를 구동: 카드 목록, 카드 -> 상세, 앵커 코드 교차 링크, 검색(`tempo`가
  워크아웃 2개로 갈라지는 충돌 배너 포함), 키보드 조회(`/`·`↑↓`·`↵`·`esc`), 최근 본 항목,
  워크아웃 SVG, 없는 URL의 폴백 — 전부 통과, **콘솔 오류 없음**, 그리고 내비게이션마다
  전역 마커가 살아남는 것으로 **전체 리로드가 없음**을 확인했다.

## 다시 열 조건

ADR 0004의 목록을 이어받는다. 라우팅이 데이터 로딩·라우트별 코드 분할·중첩 레이아웃을
필요로 하게 되거나, 번들이 실제 독자에게 **측정된** 문제가 되거나, 프리렌더 검사가 깨지고
통과시킬 수 없을 때. 여기에 하나를 더한다: **`out/*.svg`의 직렬화나 하이드레이션 페이로드의
NUL 바이트가 실제로 무언가를 깨뜨리면**, 그 도구를 바꾸는 것이 아니라 이 문서를 다시 연다.
