# ADR 0009 — 브라우즈 계층을 Remix 3로 옮긴다

**상태:** [ADR 0010](0010-tanstack-start.md)이 대체함 · 2026-08-10
**대체한 것:** [ADR 0004](0004-tanstack-router.md)(TanStack Router), [ADR 0003](0003-nub-runtime.md)(nub), 그리고 [ADR 0002](0002-component-model.md)의 React 부분

---

## 맥락

ADR 0004는 툴체인 질문을 닫으면서 다시 열 조건 셋을 적어뒀다. 라우팅이 데이터 로딩이나
중첩 레이아웃을 필요로 하거나, 번들이 실측 문제가 되거나, 프리렌더 동등성 검사가 깨지는
경우. 이번 이동은 그중 어느 것도 아니다. **저장소 소유자가 Remix 3로 옮기기를 요청했다.**

그래서 이 ADR이 기록하는 것은 "왜 옮겼는가"가 아니라 **무엇을 지켜야 이동이 손실이 아닌가**
이다. 지켜야 할 것은 ADR 0001이 세운 사전 형태다.

- 엔트리마다 디스크에 실제 문서가 하나씩 있고, 각자의 `<title>`·description·canonical·OG를
  들고 있다(발견).
- 한 번 로드되면 전체 리로드 없이 넘어가는 조회 도구가 된다(사용).
- 시각물은 데이터의 함수다. 프리렌더된 페이지와 브라우저가 보여주는 페이지가 갈라질 수 없다.
- GitHub Pages에 정적 파일로 나간다. 서버 재작성 규칙 없음.

Remix 3(`remix@3.0.0-beta.5`)는 서버 우선 프레임워크이고, UI 계층은 React가 **아니다**.
그래서 이 이동은 라우터 교체가 아니라 앱 계층 전체의 재작성이다.

## 결정

**Remix 3를 채택한다. 정적 내보내기를 유지한다.**

### 서버 우선 프레임워크로 정적 사이트를 만든다

Remix 3의 라우터는 `Request -> Response`다. 그래서 프리렌더러가 할 일이 하나로 줄었다:
라우트마다 `router.fetch()`를 부르고 응답 본문을 파일로 쓴다(`scripts/prerender.ts`).
개발 서버가 답하는 것과 프리렌더된 파일이 **같은 응답**이므로, ADR 0001의 핵심 성질이
"두 호스트가 같은 원천에서 렌더한다"에서 "두 호스트가 같은 응답을 쓴다"로 더 강해졌다.
동등성 검사가 필요 없어진 것이 아니라, 검사할 차이가 남지 않았다.

에셋도 같은 방식이다. `assetServer.getPreloads()`가 브라우저 모듈의 임포트 그래프를
돌려주고, 프리렌더러가 그것을 하나씩 받아 `dist/`에 굽는다.

### 컴포넌트는 `remix/ui`로 다시 쓴다

React 컴포넌트 약 1,300줄이 `remix/ui` 모델로 옮겨졌다. 함수가 JSX를 돌려주는 대신
`handle`을 받아 **인자 없는 렌더 함수**를 돌려준다. 기계적인 변환이었지만 두 곳에서
실제로 설계가 바뀌었다.

- **`ViewContext`가 사라졌다.** 컴포넌트마다 `ctx`를 넘기던 제약은 뷰가 프리렌더러와
  브라우저 양쪽에서 렌더되어야 한다는 데서 왔다. 이제 뷰는 서버 전용이고 브라우저는 좁은
  클라이언트 엔트리만 받으므로, 컴포넌트가 `app/data/index.ts`를 직접 임포트한다.
- **`dangerouslySetInnerHTML`이 없다.** 워크아웃 도식 SVG는 문자열로 조립돼 그 구멍으로
  들어가고 있었다. `remix/ui`에는 그 탈출구가 없고, 없는 편이 나았다 — 도형이 JSX가 되면서
  (`app/ui/chart.tsx`) 브라우즈 UI와 CLI가 **하나의 정의**를 렌더한다. 문자열이 필요한 쪽
  (`out/*.svg`)은 그 컴포넌트를 `renderToString`으로 렌더해서 얻는다.

### 검색은 클라이언트에 남고, 코퍼스는 번들에서 나온다

서버 우선 프레임워크에서 검색은 `?q=`를 읽는 액션 하나면 된다. 그런데 정적 파일은 질의
문자열을 볼 수 없다. 그래서 검색은 예전과 마찬가지로 브라우저에서 돈다
(`app/assets/search.tsx`).

달라진 것: Remix 3의 에셋 서버는 JSON 임포트를 브라우저 모듈로 컴파일하지 않는다. 그래서
코퍼스 전체를 번들에 싣던 방식(ADR 0001은 그것이 요점이라고 적었다)이 불가능해졌고,
검색이 실제로 읽는 필드만 담은 색인이 `/search-index.json`으로 나간다. 첫 키 입력에서 한
번 받고 서비스 워커가 캐시한다. 초기 페이로드는 줄었고, **오프라인에서 한 번도 열지 않은
엔트리를 검색하는 능력은 색인을 한 번이라도 받아온 뒤로 미뤄졌다.** 이건 실제 손실이다.

## 결과

**얻은 것**

- 문서 셸이 `index.html` 문자열 치환에서 컴포넌트 props가 됐다. 엔트리별 메타데이터가
  이제 액션이 건네주는 값이다(`app/actions/controller.tsx`).
- 의존성이 줄었다. React·react-dom·TanStack Router·Vite 번들러·nub·Astryx·StyleX가 나가고
  `remix` 하나가 들어왔다. 스크립트는 `remix/node-tsx`로 돌고, 테스트는 Node 내장 러너로
  돈다.
- 링크 클릭은 런타임이 가로채 문서를 통째로 교체한다(`run()`의 `resolveFrame`). 프리렌더된
  진짜 문서를 쓰면서 전체 리로드가 없다 — ADR 0004가 지키려 했던 성질이 라우터 없이 남았다.

**치른 것, 그리고 남은 함정**

- **베타에 묶였다.** `remix@3.0.0-beta.5`는 정확한 버전으로 고정돼 있다. 아래 두 항목은
  둘 다 이 버전의 동작이다.
- **`tsconfig.json`에 `jsxImportSource`를 넣을 수 없다.** 넣으면 `remix/node-tsx`가 `.ts`
  **진입 파일**을 `remix/dist/ui/` 기준으로 해석해서 못 찾는다(`.tsx`는 멀쩡하다). 그래서
  JSX 파일마다 `/** @jsxImportSource remix/ui */` 프라그마가 첫 줄에 있다. 프라그마를 빼면
  React 런타임으로 컴파일되고, 그러면 `renderToString`이 조용히 빈 문자열을 돌려준다 —
  오류 없이.
- **클라이언트 엔트리는 최상위 노드 개수를 바꾸면 안 된다.** 바꾸면 런타임의 DOM diff가
  형제를 문서 수준에 끼워 넣으려 하고, doctype 앞에는 아무것도 들어갈 수 없어서 페이지가
  통째로 깨진다 — 콘솔 오류 하나만 남기고. `SearchPanel`과 `RecentStrip`이 늘 루트 요소
  하나를 렌더하는 이유다.
- **배포 base가 두 곳에서 붙는다.** 문서 라우트는 사이트 루트 기준으로 정의되고 base는
  링크를 쓸 때 `app/ui/href.ts`가 붙인다. 브라우저 모듈만은 base가 마운트 지점 자체에
  들어간다(`ASSET_BASE`) — 컴파일러가 모듈끼리의 임포트를 자기 basePath 기준으로 다시 쓰기
  때문이다. 이 비대칭을 지우면 base가 `/`인 개발 서버에서는 멀쩡히 통과하면서 배포된
  사이트에서만 임포트가 전부 깨진다. 실제로 한 번 그렇게 깨졌다.
- **Vite+는 남지만 빌드는 하지 않는다.** `vp check`(포맷·린트·타입 검사)만 쓴다.
  `vp test`는 이 저장소에서 이미 깨져 있었다 — 카탈로그가 `latest`로 고정한
  `@voidzero-dev/vite-plus-test@0.1.24`에 `vitest` bin 항목이 없다 — 그래서 테스트는
  Node 내장 러너(`node --test`)와 `remix/assert`로 옮겼고, 그 덕에 CI가 처음으로 테스트를
  돌린다.

## 검증

- 프리렌더: 47개 라우트 + `404.html` + `search-index.json` + 브라우저 모듈 62개.
- 실제 브라우저(Chromium)로 배포 base(`/running-training-dataset/`) 아래에 서빙한 `dist/`를
  구동: 카드 목록, 카드 -> 상세 이동, 앵커 코드 교차 링크, 검색(`tempo`가 워크아웃 2개로
  갈라지는 충돌 배너 포함), 키보드 조회, 최근 본 항목, 워크아웃 SVG, 없는 URL의 폴백 —
  전부 통과, 콘솔 오류 없음.
- 데이터 규칙 테스트 14개 통과. `vp check` 무경고.

## 다시 열 조건

ADR 0004의 목록을 그대로 이어받되 하나를 더한다: **`remix`가 정식 릴리스되면 고정을 풀고
위의 두 베타 우회(프라그마, 단일 루트)가 아직 필요한지 확인한다.**
